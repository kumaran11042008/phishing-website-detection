About This Project

The Phishing Website Detection System is an Artificial Intelligence based cybersecurity application developed using Python, Flask, Scikit-learn and Random Forest.

The system analyzes URL features and webpage characteristics to determine whether a website is legitimate or phishing. It helps users stay protected from online fraud, credential theft, and malicious websites.

  • ✔ Machine Learning Based Detection
  • ✔ Real-Time URL Analysis
  • ✔ Cybersecurity Dashboard
  • ✔ Fast & Accurate Prediction
